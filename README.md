# 🔍 Wireshark SOC & Traffic Analysis Labs

This repository contains my solutions, scorecards, and documentation for the 6 hands-on SOC and Wireshark labs completed during my cybersecurity internship[cite: 5, 7].

## 📋 Labs Overview & Explanations

1. **Lab 3: Identify the Attacker's IP**
   - **Explanation:** Analyzed packet captures to trace malicious connection origins, isolated the suspicious IP address responsible for unauthorized network scanning, and documented the attacker's footprint.

2. **Lab 4: Follow TCP Stream 1**
   - **Explanation:** Rebuilt TCP communication streams in Wireshark to trace client-server handshakes, inspect clear-text chat dialogs, and extract readable text from packet data flows. *(Score: 100/100)*[cite: 8]

3. **Lab 5: Follow TCP Stream, Part 2**
   - **Explanation:** Performed advanced stream reconstruction to uncover hidden data and payloads embedded within network traffic captures.

4. **Lab 6: HTTP Plain Text Credentials**
   - **Explanation:** Inspected unencrypted HTTP traffic to identify insecure authentication methods and extract clear-text usernames and passwords.

5. **Lab 7: Catch the Brute Force Attacker**
   - **Explanation:** Spotted repeated failed login attempts and high-frequency request patterns to detect an active brute-force password cracking attack.

6. **Lab 8: Catch the Call Scammer**
   - **Explanation:** Investigated VoIP packet captures, analyzed session initiation protocols (SIP), and reviewed call flows to identify fraudulent scam call patterns.
